# Sunder

**Ancient craft. Modern utility.**

Sunder brings smooth chat, clear conversations and useful tools together in a modular interface built to feel at home in Azeroth.

## Sunder Chat

Compact tabs, smooth scrolling, horizontal background fades, shared content padding and individual growing chat editors. Move and resize your windows with Sunder's standalone layout editor or optional Ellesmere Edit UI integration.

## Whispers, together

Keep conversations in one Whispers window with All, Unread and Favorites views. Use a people list or conversation tabs, pin important conversations, create optional named groups, or detach a conversation. Customize sounds and notifications, and return directly to the right person from a toaster. Retain local conversation history with timestamps and distinguish your replies at a glance.

## Item protection

Mark individual bag items with visible lock badges and quick bag controls. Sunder stores the selected physical item copy and applies a native item lock. This first implementation is strict: remove protection before moving or using that copy. Ordinary pickup blocking has been tested on the development client; protection against every sale/trade/destruction route is still under validation.

## Your interface

Use shared typography, colors, background opacity and spacing, with optional Whispers styling overrides. EllesmereUI is optional: native fonts, settings and standalone movement controls remain available without it.

Open settings with `/sunder`. `/sun` is available when no other addon owns it.

## Existing users

Use the first-upgrade bundle and data-only loader to migrate the previous addon's profiles, saved messages, favorites, protected-item records and layouts. Once Sunder has successfully saved its own data, normal updates use the clean Sunder package.

## Client status

Initially developed on WoW Forever. Additional WoW client versions require direct validation; supported file tags should reflect tested clients only.
